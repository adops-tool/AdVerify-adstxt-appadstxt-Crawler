### Требования
* Python 3.8+
* Установите необходимые библиотеки через командную строку или терминал:
  ```bash
  pip install aiohttp tqdm
  ```

### Как использовать
1. Поместите ваши списки доменов в ту же папку, где находится скрипт.
2. Убедитесь, что названия текстовых файлов начинаются со слова `domains` и заканчиваются на `.txt` (например, `domains1.txt`, `domains_list.txt`).
3. Запустите скрипт:
   ```bash
   python adstxtcrawler.py
   ```
4. Скрипт создаст два файла: `has_ads.txt` и `has_app_ads.txt`, в которых будут сохранены домены с найденными файлами.

### Ключевые особенности и нюансы
* **Поддержка нескольких файлов:** Скрипт автоматически находит и объединяет все файлы по маске `domains*.txt`.
* **Автоматическое удаление дублей:** Повторяющиеся домены в исходных списках автоматически удаляются до начала проверки.
* **Рандомизация:** Итоговый список перемешивается в случайном порядке перед началом работы, чтобы не отправлять запросы на одну и ту же инфраструктуру подряд.
* **Безопасный перезапуск (без дублей):** Если остановить и запустить скрипт заново, он прочитает уже существующие файлы `has_ads.txt` и `has_app_ads.txt`. Он **не будет** записывать домены повторно и пропустит сетевые запросы для сайтов, которые уже были проверены ранее.
* **Потоковая запись:** Результаты записываются на диск моментально после нахождения. В случае сбоя или ручной остановки скрипта ни один найденный домен не потеряется.
* **Тихий режим:** Внутренние сетевые ошибки (например, ошибки DNS для неработающих сайтов) подавляются, чтобы консоль оставалась чистой. Отображается только полоса загрузки.
